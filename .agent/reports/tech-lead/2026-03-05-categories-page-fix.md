## Проблема 2: Плохой контраст текста внутри плиток категорий в светлой теме

### Симптом

В светлой теме заголовок и описание внутри плиток категорий (`<h2>` и `<p>`) становятся практически невидимыми.

### Причина

Плитки используют градиентный фон (например, `from-blue-500 to-cyan-500`), а текст имеет класс `text-white/90` (т.е. `rgba(255, 255, 255, 0.9)`). В тёмной теме контраст достаточен. В светлой теме контрастность может быть ниже нормы WCAG AA (4.5:1 для обычного текста).

### Ссылка на файл скила

`.roo/skills/frontend-contrast-fix.md` — содержит шаблонные инструкции по проверке и исправлению контраста.

### Что нужно сделать

1. Проверить контрастность `white/90` текста на фоне существующих градиентных пар (blue/cyan, purple/pink, green/emerald, orange/red) с помощью инструментов или расчёта.
2. Если контрастность ниже WCAG AA: добавить тень к тексту (`drop-shadow` / `text-shadow`) или добавить затемняющий overlay под текстом.
3. Рекомендуемое решение — добавить `drop-shadow` к контейнеру текста:
   ```html
   <div class="relative z-10 drop-shadow-[0_1px_3px_rgba(0,0,0,0.4)]">
   ```
   Или добавить полупрозрачный тёмный overlay постоянно (не только на hover):
   ```html
   <div class="absolute inset-0 bg-black/20 rounded-2xl"></div>
   ```
4. Проверить результат в светлой теме через браузер.
