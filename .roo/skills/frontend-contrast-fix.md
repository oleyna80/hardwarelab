# Frontend Contrast Fix (Astro / Tailwind)

## Контекст (Диагноз)
- **Суть проблемы:** Текст в светлой теме выглядит "блеклым", недостаточно контрастным.
- **Причина:** Использование `text-primary-900` (`#312e81`, тёмный индиго) поверх `bg-primary-50` (`#eef2ff`). Хоть это и тёмный цвет, он не даёт нужного контраста для чтения больших объемов текста и заголовков.
- **Где возникает:** `src/layouts/Layout.astro` в классе `<body>`. Заголовки (h1, h2) на многих страницах не имеют жестко заданного цвета текста и наследуют его из `<body>`.

## Задача для RuCode
Если вы работаете над подобной задачей или восстанавливаете этот фикс, следуйте этим шагам:

1. Откройте файл `src/layouts/Layout.astro`.
2. Найдите тег `<body>` (обычно около строки 59).
3. Измените класс светлой темы:
   - Было: `class="bg-primary-50 text-primary-900 dark:bg-primary-950 dark:text-primary-100..."`
   - Стало: `class="bg-primary-50 text-gray-900 dark:bg-primary-950 dark:text-primary-100..."`
4. **Важно:** Мы меняем *только* светлую тему (`text-primary-900` -> `text-gray-900`). Цвета тёмной темы (`dark:text-primary-100`) остаются без изменений.
5. `text-gray-900` (`#18181b`) дает глубокий, почти черный цвет, что идеально для читаемости.

## Проверка результатов
- Запустите сервер: `npm run dev`
- Откройте `http://localhost:4321/categories` в светлой теме.
- Убедитесь, что заголовки и основной текст стали четко темными (почти черными).
- Переключитесь на темную тему — убедитесь, что она не сломалась (текст должен остаться светлым индиго `primary-100`).
- Проверьте другие страницы (Homepage, Reviews) — они тоже унаследовали этот фикс и должны выглядеть лучше.
