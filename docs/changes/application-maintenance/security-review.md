## Boundaries and changes

Contact reads at most 16 KiB during streaming; rejected oversized streams do not explicitly cancel their reader. Origin, IP rate limits, optional Turnstile, restricted webhook host and request timeouts were inspected. A Turnstile request could wait indefinitely; an allowed webhook could redirect outside the validated host. The candidate adds a five-second abort and rejects redirects. Synthetic mocked tests exercise success/failure and abort, but not real provider or native redirect transport. Proxy header trust, per-process rate limits, default optional Turnstile, hostname/action validation and actual provider behavior depend on production configuration, which was not observed. The contact page exposes mailto; no client call to the exported API was found in the inspected source, although a direct HTTP route exists.

JSON-LD previously placed `JSON.stringify` output in raw HTML, allowing a `</script>` in repository-controlled content to terminate the tag. The candidate escapes `<`; the Coder's synthetic Chromium DOMParser check preserved JSON and prevented an injected element. No public-user input path into that content or full synthetic SSR test was established. Image inputs and MDX are repository-controlled; edge headers/CSP, deployment proxy, secrets and production configuration remain unobserved. No production contact or provider requests were made. Frontend security guidance from the local security-best-practices skill was consulted.
