# Architecture and Engineering Decisions

This directory is the **only** canonical home for durable rationale and project-wide engineering decisions.

- One decision per file, e.g. `0001-lite-foundation.md`.
- Include: status (`proposed`, `accepted`, `superseded`), date, context, decision, rationale, consequences, evidence and revisiting trigger.
- A replacement decision references the superseded one; do not erase accepted history.
- Operational `memory_bank/decisions.md` contains **links and status only**, not repeated reasoning.
- Templates and subagent opinions are not accepted decisions. Owner/approved project decision supplies acceptance.

Use [decision-record template](../templates/decision-record.md).
